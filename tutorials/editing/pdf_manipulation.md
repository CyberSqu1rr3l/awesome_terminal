- merge multiple PDF documents using: pdfunite * merged_output.pdf or
  pdfunite <infile1>.pdf <infile2>.pdf ... <outfile>.pdf
  this tool requires the poppler-utils package: apt install poppler-utils
- concatenate multiple files to one PDF file: convert <images>*.jpg <filename>.pdf
  imagemagic may need to be installed: sudo apt install graphicsmagick-imagemagick-compat
