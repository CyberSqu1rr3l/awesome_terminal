# signal-cli

Signal is an open-source end-to-end encrypted messenger commonly used for secure communication. [^2]

The independent `signal-cli` [^1] command-line client enables sending and receiving Signal messages directly from the terminal. By integrating it into scripts, we can automate notifications, monitor servers, or build chatbots.
